空格播放 / 暂停

L锁定 / 解锁：重新生成方案时保持不变
Enter试听当前片段（前后各多放 1 秒，不跳过）
[ ]把当前边界提前 / 推后 50ms（加 ⇧ 为 500ms）。想“多留 / 少留”一点，用选中行上的按钮更直观
E切换微调的是起点还是终点
← →后退 / 前进 1 秒（加 ⇧ 为 5 秒）
⌘Z撤销（⇧⌘Z 重做）
↑ ↓候选清单里切换候选
S候选清单里勾选 / 取消当前候选
?打开这个窗口
这页怎么用（几个概念）
拿不准
机器对这个决定的把握度低于 75%。没有拿不准，不等于都对：可以点“抽查”，按把握度从低到高看。
锁定
锁定的片段，改节奏时不会被动（手改过的片段也一样）。
节奏
每个停顿保留多长：紧凑 0.15 秒、自然 0.4 秒、从容 0.8 秒。点另一档会在页面里重新划分停顿，可以撤销。
字幕
“烧进画面”是画在视频上；“单独 srt”只另外写一个文件。预览里叠加的字幕按当前选择显示。
导出的文件
和方案文件放在同一个文件夹里，完成后点“在 Finder 中显示”。
方案文件
你在这里改的和 agent 在终端里改的是同一份 .autocut.json。别人改了会标出来，你可以逐处接受或撤销；两边改了同一处，会让你逐条选。

字号：点工具栏的 Aa 切换，或者用 ⌘+ 放大整个页面。所有改动自动保存，也可以随时在终端里让 agent 接着改同一份方案文件。

出片选项

字幕
响度
成片尺寸

字幕和尺寸会写进方案（可以 ⌘Z 撤销）；响度只对这次出片生效。体检里的建议按钮改的就是这几项。
