## 张力与开放问题

- **"所有类型都要"和"别为所有人设计"之间有矛盾。** HCI 的做法是选一个主 persona 作为设计目标，其余作为次要 persona。这里的对应办法是：概念模型要通用（所有类型共用一套 素材 → 信号 → 方案 → 审阅 → 成片），但交互和默认值要为主 persona 调优，其他类型靠"配方"扩展。到 Define 阶段由证据决定谁是主 persona。
- **"爆款"不由剪辑单独决定。** 选题、时机、平台算法和账号基础都起作用。我们只对剪辑能影响的部分负责：钩子、节奏、死寂、字幕、画幅、响度、高光命中、卡点。这一点要在问题陈述和测试计划里写明，不能过度承诺。
- **R1 隐含 agent 是一类用户。** 需求方本人长期通过 Claude Code 工作，很可能会委托 agent 来剪（"帮我把这个直播切 3 条"）。这样一来，人类侧的界面有很大一部分是 agent 交回来的结果、摘要和审阅页，而不是传统剪辑软件。
- **需要追问需求方的具体经历**（访谈规则：问具体的过去事件，不问愿望）：最近一次剪的是什么视频？在哪一步最花时间？哪条视频的数据最好，当时剪辑上做了什么不同的处理？这些问题已写进 `01-empathize/interview-guide.md`，作为"需求方访谈"首个场次。
