# 用户与利益相关者图

证据等级：**requester + assumption**（traces 回来后补来源）· 日期：2026-10-28

## 用户与利益相关者

| 类别 | 谁 | 和产品的关系 | 他们会失去 / 得到什么 |
|---|---|---|---|
| 主要用户（直接使用） | 一人包揽的多形态创作者（口播/知识、游戏实况、混剪、鬼畜） | 导入素材、审阅初稿、导出 | 时间、更新频率、作品数据 |
| 主要用户 | 切片作者（替主播或自己出直播切片） | 批量处理长录像，追时效 | 时效窗口内的播放量 |
| 主要用户 | 委托 agent 干活的开发者型创作者（如需求方） | 用自然语言下达任务，读 agent 的结果与摘要 | 审阅成本、token 花费 |
| 次要用户（受影响/有影响） | 观众 | 看成片；完播和互动决定"爆款" | 注意力；被无聊段落、没字幕、画幅不对劝退 |
| 次要用户 | 接手精剪的剪辑师 / 合作者 | 打开粗剪工程（FCPXML/EDL）继续做 | 返工量；工程能不能打开、对不对得上 |
| 次要用户 | AI agent（Claude Code 等） | 通过 CLI/MCP/skill 操作工具 | 见 `docs/agent-design/autocut/` |
| 间接 | 平台（抖音、B站、YouTube）及其推荐算法 | 决定分发；有画幅、时长、字幕方面的惯例 | — |
| 权利人 | 被切片的主播、被鬼畜的人、音乐和影视版权方 | 素材来源 | 版权、肖像、名誉 |
| 运营者 | 维护 autocut 的开发者 | 接收 issue、维护配方 | 维护成本 |

## 用户特征（profile 维度）

| 维度 | 分布（待验证） | 设计含义 |
|---|---|---|
| 年龄 / 身份 | 学生到全职创作者 [A] | 免费、本地运行、默认值要好 |
| 技术经验 | 从只会剪映到会写脚本、用 Claude Code [A] | 人类界面不能要求命令行；agent 路径和人类路径都要是一等公民 |
| 语言 | 中文为主，也有英文素材 [requester] | 中文字幕、中文 ASR 准确度、中文文案语气 |
| 能力差异 | 听障观众依赖字幕；色弱用户审阅时间线 [A] | 字幕默认开；时间线不能只靠颜色区分"保留/剪掉" |
| 动机 | 更新频率、数据、表达欲；鬼畜作者重视手艺 [A] | 自动化要能被接管，不能抢走创作决定 |
| 环境 | 自己电脑上的长时间剪辑；切片要赶时效；常被打断 [A] | 可中断、可恢复；结果可以先预览，不必先渲染 |
