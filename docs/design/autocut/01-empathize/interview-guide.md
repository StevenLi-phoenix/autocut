# 访谈指南 — 视频创作者的剪辑过程

问题陈述（1–2 行）：一人包揽的多形态视频创作者，从原始素材到可发布成片的过程中，在机械性判断上花掉大量时间，而成片表现（完播、互动）又取决于这些判断做得好不好。见 `problem-statement-v0.md`。
形式：半结构化 · 30–40 分钟 · 尽量在对方剪辑的电脑前（contextual inquiry：请对方打开最近的一个工程）· 访谈者：主持 1 人、记录 1 人
首个场次：需求方本人（见 `../00-requester-account.md`），之后每种形态各找 2–3 位创作者（不找亲友、不找有权力关系的人）

## 1. 开场（约 2 分钟）
"你好，谢谢你抽时间。我是 ___，这位是 ___，负责记笔记。我们在研究视频创作者是怎么剪片子的，想了解你的真实经历，没有对错之分。大概 35 分钟。可以录音吗？录音只给我们团队做研究用，报告里不会出现你的名字或账号。任何问题都可以跳过，你也可以随时停下来。开始前你有什么想问的吗？"

## 2. 热身（约 3 分钟）
- 你平时做哪些类型的视频？在哪些平台发？
- 最近一周，你花在视频上的时间大概都用在了哪些事情上？

## 3. 主体

### 主题 A：最近一次从素材到成片
- 跟我讲讲你最近剪的一条视频，从素材拷进电脑开始，一步一步走一遍。
  - 探问：然后呢？这一步你用的是什么？能打开工程给我看看吗？
- 那一次里，哪一段花的时间最长？当时你在做什么？
- 什么地方让你剪着剪着烦了，或者想放弃？
- （换个问法）如果把那次剪辑的过程画成一条时间线，最费劲的是哪一段，为什么？

### 主题 B：判断"该剪"和"剪得好"
- 你在时间线上决定"这一段不要了"的时候，依据是什么？举一个最近的例子。
- 你怎么判断一个停顿、一句口误、一段没人说话的游戏画面该不该留？
- 跟我讲讲一条你觉得剪得特别好的视频，它好在哪？
- 发布之后，你会看哪些数据？最近一次看数据之后，你回头改了什么？
  - 探问：留存曲线在哪里掉下去的？你当时觉得原因是什么？
- 你认为数据最好的那一条，剪辑上和其他几条有什么不同？

### 主题 C：自动化工具与信任
- 跟我讲讲你最近一次用自动剪辑功能的经历（剪映智能剪口播、自动字幕、一键成片、Opus Clip、auto-editor 之类，或者你自己写的脚本）。
  - 探问：结果出来以后你做了什么？你怎么确认它没剪错？
- 自动结果里，哪一次让你最不放心？当时发生了什么？
- 你最后在哪里修改自动出来的结果：剪辑软件时间线、文字稿，还是重新跑一遍？为什么在那里改？
- 什么样的剪辑你宁愿自己一刀一刀剪，为什么？

### 主题 D：不同形态之间的差别
- 你做 [切片 / 混剪 / 鬼畜 / 知识视频 / 游戏实况] 的时候，流程和刚才说的那条有什么不一样？
- 跟我讲讲你最近一次做 [该形态]：素材从哪来？最费时间的是哪一步？
- （鬼畜/混剪）扒谱、对拍、选素材这些步骤，你最近一次是怎么做的？
- （切片）直播结束到切片发出去，中间隔了多久？时间都花在哪？
- （知识视频）从文稿到配音、配图、字幕，你是按什么顺序做的？哪一步返工最多？

## 4. 收尾（约 3 分钟）
- 关于剪辑这件事，你还有什么想法或建议？
- **还有什么我们没聊到、但你觉得重要的吗？**
- 谢谢你！（留联系方式；说明之后可能请你试用原型）

## 预检清单
- [x] 每个问题都是开放式的，不引导、不假设，不问"你想要什么功能"
- [x] Lint：主问题和探问都不以"是不是 / 有没有 / 会不会 / 能不能 / 你觉得…吗"这类封闭句式开头（收尾那句"还有什么我们没聊到"除外）；都用"跟我讲讲 / 怎么 / 什么 / 哪 / 为什么"
- [x] 不问"一般多久 / 多常"之类需要估算的问题，而是问具体某一次
- [x] 关键问题准备了 2–3 种问法（主题 A、B）
- [ ] 先找一个人试访一次（待做）
- [ ] 录音许可和匿名化方案准备好；记录表包含地点、在场者、对方展示的工程/工具
